# Майстерня

Приватний застосунок для обліку замовлень ювелірної майстерні (S.A.R.A.N.C.H.U.K.).
Один файл `index.html`, дані в Firebase Firestore, вхід за поштою й паролем.

- `index.html`: увесь застосунок
- `sw.js`, `manifest.webmanifest`, `*.png`: робота без інтернету та іконка на головному екрані
- `firestore.rules`: правила доступу до бази (вставляються в Firebase Console → Firestore → Rules)
