# Іконки ресурсів (екран «Склад»)

Сюди кладуться локальні іконки плиток ресурсів. Поки файлів немає, застосунок показує універсальну технічну піктограму.

Вимоги до файлу: WebP (або PNG), прозорий фон, квадрат 96×96 px (показується ~48 px, 2× для Retina), приглушене освітлення, однакова перспектива, вага до 15 КБ.

Імена файлів (ключ = ім'я файлу без розширення):

| Ресурс | Файл |
|---|---|
| Срібло | `silver.webp` |
| Золото | `gold.webp` |
| Флюс | `flux.webp` |
| Припій | `solder.webp` |
| Газ у балоні | `gas.webp` |
| Рідина для ультразвуку | `ultrasonic.webp` |
| Чорніння | `blackening.webp` |

Після додавання файлу відкрийте `index.html`, знайдіть `RES_ICONS` і поставте `true` навпроти ключа, наприклад `{silver:true}`. Ресурси, яких немає в таблиці, завжди показують універсальну піктограму.
